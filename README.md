# AURA ATLAS

Неофициальный фан-атлас Pokémon для знакомства с персонажами и первого изучения типов. Сохраняет туманную зелень, кремовую бумагу и любимую подборку.

**Сайт:** https://isefdk.github.io/aura-atlas/

## Зачем пользоваться

1. Найди любимого в покедексе и изучи типы, характеристики и эволюцию
2. Собери учебный состав до шести видов и посмотри, какие атаки опасны для нескольких участников и у кого есть сопротивление по типам
3. Прочитай три коротких примера в блокноте, проверь вывод и запиши свои наблюдения

## Что внутри

- 55 настоящих публичных страниц: 47 карточек видов, главная, покедекс, команда, блокнот, три объяснения и источники
- Исходные 24 избранных Pokémon и 23 дополнительных участника их полных эволюционных семейств
- Все ссылки на родственников открывают полноценные страницы внутри атласа, включая Риолу, Гибла, Фроки и остальные этапы
- Поиск по русскому/английскому имени и номеру, фильтры типов/поколений, сортировка, режим «Избранные» или «Все семейства», URL-состояние и история браузера
- Точный локальный снимок PokeAPI: характеристики обычных форм, типы, способности, размеры и полные условия эволюции
- Команда до шести уникальных видов, локальное сохранение и экспорт JSON
- Карта защиты по всем 18 типам, именованные слабости и сопротивления, ×4/×0 и подсказка общих незащищённых слабостей
- Три учебных пути чтения, сохранённые записи и личный блокнот с экспортом TXT
- На главной надёжный учебный инструмент: выбери покемона и входящий тип атаки, получи множитель; работает без WebGL и GPU
- Главная сцена с Грениндзя: специально сгенерированный фан-арт. Карточки используют официальные изображения с атрибуцией

## Локальный запуск

Node.js 22+; Python 3 нужен только для удобного локального сервера. Никаких npm-зависимостей.

```sh
npm run build
npm test
node scripts/acquire-related.mjs --check
npm run serve
```

Открой http://localhost:4175. GitHub Pages публикует ветку `main`, папку `docs`. Файлы CSS/JS имеют хэш в имени, включая транзитивные импорты, чтобы обновления не смешивались с кешем старой версии.

## Данные и ограничения

Источники и контрольные суммы: `data/README.md`, `data/provenance.json`, `data/related-provenance.json`. Исходные материалы отделены от авторских объяснений. Приложение не запрашивает PokeAPI во время работы. PokeAPI — общественный справочник, а не официальный API игр Pokémon.

Избранные данные и таблица типов получены 2026-10-03. Дополнительные карточки семейств получены 2026-10-05; условия эволюции сохраняют исходный снимок 2026-10-03. Условия могут различаться между играми и формами. Краткие подписи показывают основную доступную ветку, полный JSON сохраняет альтернативы.

Анализ защиты считает только множители типов для обычных форм. Он исключает способности, предметы, погоду, уровень, набор приёмов, альтернативные формы, терасталлизацию и особые правила приёмов. Это учебный инструмент, а не рейтинг команды, подбор победного состава или гарантия безопасного переключения.

Команда, закладки и заметки используют прежние ключи localStorage, поэтому обновление сохраняет существующие данные. Всё хранится только в этом браузере. Если сохранение запрещено, приложение сообщает об этом и предлагает экспорт. Учебный пример добавляет участников в свободные места, не заменяя сохранённый состав.

## Права

Некоммерческий фан-проект не связан с Nintendo, Creatures Inc., Game Freak или The Pokémon Company и не заявляет о лицензии. Pokémon, имена и официальные изображения принадлежат правообладателям. Источник изображений: PokeAPI/sprites. Главная иллюстрация создана генерацией изображений; происхождение записано в `artwork/hero-greninja-provenance.json`.

MIT распространяется на исходный код и собственные элементы, но не на персонажей и изображения Pokémon. Manrope распространяется под SIL Open Font License (`public/fonts/OFL.txt`).

## Проверка

Domain/data тесты проверяют таблицу типов, множители ×4 и ×0, точность данных, команды, фильтры, URL и целостность ассетов. Статический аудит проверяет все реальные маршруты, эволюционные ссылки, относительные ссылки, семантику и воспроизводимость сборки. DOM-double тесты запускают настоящий код обработчиков: сохранение, поиск, историю, клавиатуру, обновления между вкладками и учебную проверку типов.

`qa.html`, скрытая из навигации и индексирования, предназначена для визуальной проверки 320/390/768/1440 px. GitHub Actions проверяет тесты и воспроизводимость опубликованной сборки.
