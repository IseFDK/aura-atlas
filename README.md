# AURA ATLAS

Неофициальный полевой атлас Pokémon. Туманная зелень, кремовая бумага, 24 выразительных персонажа и небольшая история вокруг каждого.

**Сайт:** https://isefdk.github.io/aura-atlas/

## Что внутри

- 32 настоящие страницы: главная, покедекс, 24 карточки видов, команда, дневник, 3 записи и источники
- Поиск по русскому/английскому имени и номеру, фильтры типов/поколений, сортировка, URL-состояние и история браузера
- Точный локальный снимок PokeAPI: характеристики обычных форм, типы, способности, размеры, полные эволюционные семейства
- Команда до 6 уникальных видов, сохранение на устройстве, экспорт JSON, защита по всем 18 типам с двойными слабостями и иммунитетами
- Авторский фан-дневник, три вымышленных маршрута, сохранённые записи и личный блокнот с экспортом TXT
- Оригинальная процедурная WebGL-модель полевого сканера, собственный SVG fallback, пауза и reduced-motion
- Главная сцена с Грениндзя: специально сгенерированный фан-арт; карточки используют официальные изображения с атрибуцией

## Локальный запуск

Требуется Node.js 22+ и Python 3 для удобного локального сервера. Пакетов npm и внешних библиотек нет.

```sh
npm test
npm run build
npm run serve
```

Открой http://localhost:4175. GitHub Pages публикует ветку `main`, папку `docs`.

## Данные

Снимок и происхождение: `data/README.md`, `data/provenance.json`. Канонические исходники сохраняются отдельно от авторских текстов. Приложение не запрашивает PokeAPI во время работы. JSON-снимок также доступен на сайте.

Условия эволюции могут различаться между играми и формами. Краткие подписи показывают основную доступную ветку, полный JSON сохраняет альтернативы. Анализ защиты исключает способности, предметы, погоду, альтернативные формы и особые правила приёмов. Это не рейтинг команды и не обещание победы.

Команда/заметки хранятся только в localStorage этого браузера. Серверных аккаунтов и трекинга нет. Если браузер запрещает localStorage, состав работает только до закрытия страницы и предлагает экспорт.

## Проверка

Domain/data тесты проверяют все 324 сочетания одиночных типов и 432 сочетания выбранных видов с атакующими типами, иммунитеты/×4, точность данных, команды, фильтры, URL и целостность ассетов. Дополнительный статический аудит проверяет реальные маршруты, относительные ссылки, семантику и воспроизводимость сборки. Непубличная в навигации `qa.html` предназначена для проверки адаптивности на 320/390/768/1440 px.

WebGL может быть недоступен в некоторых браузерах/средах. SVG fallback полностью автономный; основная функциональность не зависит от 3D.
