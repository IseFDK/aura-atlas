ЗАМЕТКА НА ПЕРВОЙ СТРАНИЦЕ

Мир большой.
Начни с малого.

Мы выбрали 24 вида: разные типы, выразительные силуэты и несколько любимых персонажей. Это авторская подборка, а не полный покедекс. Здесь можно посмотреть характеристики, проследить эволюцию, собрать шесть покемонов и сохранить свои заметки.

Атлас не предсказывает победы в бою. Анализ команды показывает только защитные множители типов обычных форм. Способности, предметы, конкретные приёмы и правила отдельных игр могут менять результат.

Твои данные остаются у тебя

Команда, сохранённые записи и личная заметка хранятся в localStorage этого браузера. Аккаунта и серверного хранения нет. В другом браузере их не будет. Для резервной копии скачай команду в JSON и заметку в TXT.

Числа не придуманы. Характеристики, типы, способности, рост, вес и эволюционные семейства получены из открытых данных PokeAPI. Для надёжности сайт использует локальный снимок: карточки не зависят от доступности API.

Дата снимка: 2026-10-03. Данные взяты из официального репозитория PokeAPI/api-data, точные исходные файлы и SHA сохранены в журнале источников. Русские имена локализованы вручную; игровые термины могут отличаться между переводами.

Эволюция зависит от игры

Условия на карточках показаны для основной ветки, доступной в снимке. Полный JSON сохраняет альтернативные условия, формы и группы версий. Для конкретной игры сверяй нужную ветку исходных данных.

Грениндзя на главной

Главная сцена — оригинальный фан-арт, созданный инструментом генерации изображений для этого проекта. Это не официальная иллюстрация Pokémon. Происхождение и описание генерации

Иллюстрации на карточках

Официальные изображения персонажей взяты из открытого репозитория PokeAPI/sprites. На странице каждого вида есть ссылка на оригинал. Изображения адаптированы в WebP для быстрой загрузки.

Полевой сканер

Процедурная 3D-сцена написана для атласа без внешней модели. При отсутствии WebGL показывается собственная SVG-иллюстрация. Автовращение можно остановить; при настройке уменьшенного движения оно выключено.
